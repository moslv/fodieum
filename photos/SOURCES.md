# Photographies d'événements

Originaux des affiches pour les fiches que les maquettes Stitch ne couvraient pas.
`npm run posters` les recadre en 4:3 et les convertit en WebP 640 / 1280 dans
`src/assets/posters/` — seuls ces WebP sont servis par l'application.

| Fichier | Événement | Source |
|---|---|---|
| `poster-popenguine.jpg` | Festival Plage de Popenguine | [Pexels 11653917](https://www.pexels.com/photo/11653917/) |
| `poster-saint-louis-jazz.jpg` | Saint-Louis Jazz — Édition spéciale | [Pexels 26952977](https://www.pexels.com/photo/26952977/) |
| `poster-dakar-jazz.jpg` | Dakar Jazz Festival | [Pexels 12448207](https://www.pexels.com/photo/12448207/) |

**Licence Pexels** : usage gratuit, y compris commercial, sans attribution
obligatoire. Le crédit est donné ici par correction, pas par obligation.

Les trois autres affiches (`pool-party-saly`, `fashion-week-dakar`,
`jazz-night`) viennent des maquettes Stitch et sont **générées par IA** : ce
sont des visuels de démonstration, à signaler comme tels dans le README.
